## Usage rules

Preserve aspect ratio. Keep the seal at least 72 CSS pixels wide and allow surrounding clear space of at least 12% of its diameter in page layouts. Use the cookie symbol at small sizes rather than shrinking text. Use the horizontal logo on white/cream surfaces; no reverse-white variant is included. Its lettering is artwork, not a substitute for the guide's website fonts.

Do not stretch, recolor, add shadows, or upscale beyond native resolution for print. Transparent assets have real alpha channels. The sharing banner has an opaque cream background; its badge is a generated interpretation, not an exact composite of the original. Use the original seal where exact artwork fidelity is required. No social handles, URLs, prices or temporary account details are baked into these assets.

Supply accessible text “Cookies & Chips” for a meaningful linked logo; decorative repetitions use empty alt text. Do not apply the cookie icon as a maskable app icon without checking platform safe-area requirements. Browser and social upload previews still require validation during integration.

The brand guide remains authoritative for exact interface colors and typography; generated raster artwork is not a source from which to sample UI tokens. A true editable SVG/EPS master requires a separately reviewed vector redraw or designer source.
